# GTA 6 Guide (Android)

Checkliste für alle Story-Missionen, Nebenmissionen und Aktivitäten + Live-Ticker.

- APK: unter **Releases** herunterladen (wird bei jedem Push automatisch gebaut).
- `tipps.json` bearbeiten = neue Guide-Tipps im Live-Ticker (ohne neue APK).
- `missionen.json` bearbeiten und `version` hochzählen = Missionsliste in der App wird aktualisiert.
